## 🛠 Требования
* **Python:** 3.13
* **ОС:** Windows / Linux / macOS

## 📦 Установка

**1. Клонируйте репозиторий:**
```bash
git clone https://github.com/iAmTeapotMini/relief.git
cd relief
```

**2. Создайте и активируйте виртуальное окружение:**

*Для Windows:*
```bash
python -m venv venv
venv\Scripts\activate
```

*Для macOS/Linux:*
```bash
python3 -m venv venv
source venv/bin/activate
```

**3. Установите зависимости:**
Если в корне проекта есть файл `requirements.txt`, выполните:
```bash
pip install -r requirements.txt
```

## 📁 Подготовка данных (Структура папок)

**Входные карты:** Поместите исходные растровые изображения карт (в форматах `.png` или `.jpeg`) в директорию `data/input/`.

*Примечание: Папки `data/temp/` (для промежуточных нарезок и масок) и `data/output/` (для финальных карт высот) будут очищаться и пересоздаваться автоматически при новых запусках для предотвращения конфликтов файлов.*

## 🚀 Запуск программы

Основной точкой входа в приложение является скрипт `main.py`. Программа работает в формате интерактивного консольного меню.

Для запуска выполните:
```bash
python main.py
```

Следуйте подсказкам в консоли. Ход выполнения операций сопровождается цветным логированием (ошибки, предупреждения, успешное завершение этапов).

## 🖼 Результаты работы

После успешного завершения пайплайна результаты сохраняются в директорию `data/output/`.
